# HealthHub v409 · Multimodal document knowledge-base safeguards

## What is actually built
The existing v403 Ask Léna clinical narrative engine is unchanged. The v407/v408 private knowledge-base modules load only when the user explicitly opens them from the existing archived-document card. The profile-scoped Supabase database holds PDF-page text and optional page-image snapshots, while the original signed-off PDF bytes remain unchanged in the original Drive archive. A named one-document EKG or ambulance pilot does not start the full batch or opt the device into continuous ingestion.

## Non-negotiable provenance rules
1. **Source authority is not inferred from a filename.** Ambulance/EMS filename alone does not certify that an ECG waveform exists. Terms such as “EKG: Nem történt” are negative evidence for an ECG capture; the page can still be archived as an ordinary clinical form/visual candidate. Device-origin watch recordings are explicitly not hospital-certified reports.
2. **Page-level references persist.** No short snippet may be reported as a fully ingested PDF. The entire searchable text layer of every selected page is stored with the PDF source ID and page number. Search returns page citation and snippet.
3. **OCR is not 100% ground truth.** Every page whose readable text was generated by OCR stays marked as pending human verification, and the document remains partially processed. Missing text or image upload failures also prevent a complete status.
4. **Visual snapshots are not interpretations.** Full-page lossless PNG snapshots preserve diagrams, vector-drawn ECG, bitmap attachments, units and layout; derived copies remain in an RLS-protected private bucket. The user should see an image as a visual candidate, not an AI diagnosis.
5. **Deduplication is SHA-256 only.** An identical duplicate file stays referenced as a second source file with a pointer to one canonical content object. The duplicate does not falsely claim its own stored pages or image snapshots. All originals remain intact.
6. **Profile isolation before PDF read.** The Drive archive folder is verified by finding one matching descendant of the known archive root and matching profile subfolder. A stale localStorage folder ID alone cannot determine the profile. Actual PDF metadata must identify the expected parent and compatible profile before downloading.
7. **Manual one-time indexing does not imply auto-indexing.** Continuous indexing is a separate, explicitly enabled per-device/per-profile setting. The two targeted pilots process at most one PDF each.
8. **No public medical documents.** No patient PDF text, images, or private identifiers are committed to the public app repository; only client logic, schema and synthetic tests belong there. Original PDF bytes must not be uploaded to a third-party AI without separate consent.

- v408 targeted pilot checks: 6.
- v408 lazy-loader checks: 6.

- Total 43 passing synthetic checks against branch source (including syntax checks).
- Separate **read-only local** PDF smoke test on two EMS forms and one wearable ECG: 15 pages, 19,485 extracted text characters; all 15 pages had readable text layer. Each source had image content and vector-drawing operations; the wearable ECG page contained >1,000 drawn vector elements. This local source inspection is not a clinical audit and **not** an authenticated Samsung/Supabase ingestion test.

## Deployment / acceptance gate
**Do not call the patient archive migrated until authenticated device tests actually populate Supabase and each file verifies:**
- original Drive identity + SHA-256,
- page count equality and full text page references,
- a stored and readable private image matching a real ECG/medical visual,
- explicit per-document status with OCR/manual review,
- search result with exact source file + page,
- successful cross-profile access denial,
- reliable stop/resume with no duplicate content inflation.
The central knowledge base can remain empty until this device-side pilot is successfully completed. Do not silently claim `100%` completion based only on code tests or filename matching.
